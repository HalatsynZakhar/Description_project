# Запуск MONO Excel Processor

1. Покладіть **копію** потрібної таблиці `.xlsx` до теки [input](input).
   Програма змінює цей файл без створення ще однієї копії.
2. Відкрийте [keys.example.json](keys.example.json), скопіюйте його в локальний
   `keys.json` та вставте ключі Google Gemini. Файл `keys.json` уже виключений
   з Git і не буде запушений.
3. Встановіть залежності:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

4. Запустіть програму:

   ```powershell
   .\.venv\Scripts\python.exe mono_processor.py
   ```

Під час запуску оберіть файл, аркуш, колонки вихідної назви й опису. У таблиці
з’являться колонки `Назва MONO` та `Опис MONO`.

## Надійність

- Один запит Gemini створює обидва поля, тому звичайна обробка рядка виконує
  лише один запит до моделі.
- Після кожного успішного рядка `.xlsx` зберігається атомарно. Після аварійного
  завершення може знадобитися повторно обробити лише поточний рядок.
- Рядок, у якому заповнено хоча б одну з колонок MONO, не перезаписується.
- Рядки без вихідної назви або опису пропускаються.
- Стан ключів зберігається локально в `keys_state.json`. Ключі з `401/403`
  відкладаються на 24 години, а ключі з `429` і тимчасовими помилками — на
  короткий час. Наступний запуск перевіряє їх автоматично.
- Перед кожним викликом видно номер рядка й спробу ключа. Один мережевий виклик
  обмежено двома хвилинами; після тайм-ауту програма повторює його за своїми
  правилами або переходить до наступного доступного ключа.
- Якщо Gemini повертає порожню або не-JSON відповідь, програма один раз повторює
  цей запит. Теги форматування `<strong>`, `<b>`, `<em>` та `<i>` прибираються
  локально, оскільки вони не дозволені MONO і не змінюють зміст опису.
- Перед запитом програма вилучає з вихідного тексту секції «Комплектація» та
  «Додаткова інформація»: за правилами MONO вони не повинні потрапляти до опису.
- Помилки недоступності Gemini й непридатні відповіді записуються у локальний
  файл `logs/gemini_errors.jsonl`. У журналі немає API-ключів або текстів товарів.

Модель за замовчуванням — `gemini-3.5-flash-lite`. Повний текст запиту до
моделі збережено у [prompts/mono_product_prompt.txt](prompts/mono_product_prompt.txt).

## Перевірка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Перевірка ключів

Щоб перевірити кожен увімкнений ключ із `keys.json` одним коротким запитом,
виконайте:

```powershell
.\.venv\Scripts\python.exe check_keys.py
```

Скрипт виведе `OK` із відповіддю або точну помилку для кожного ключа. Самі
значення ключів у консоль не виводяться. У PyCharm натисніть правою кнопкою на
`check_keys.py` і виберіть **Run 'check_keys'**, а не **Run pytest**. Для запуску
подвійним кліком у Провіднику є файл `check_keys.cmd`.
